## Purpose and header

`koto::Frame` maintains the front and back `cell` buffers (`m_front_buffer` and `m_back_buffer`), the `hit buffer` (`m_hit_buffer`), harvested `id` bounding boxes (`m_tag_bounds`), and the differential SGR output stream (`m_output`).
Header: `koto/frame.hpp` (included by `koto/koto.hpp`).

## Examples

```cpp
#include <koto/koto.hpp>
#include <cassert>

using namespace koto;

int main()
{
    Frame frame(4, 16);
    frame.fill(Area(0, 0, 16, 4), U'.', Color::DarkGray, Color::Default, Id("canvas"));
    frame[1, 2] = Cell{U'X', Color::Cyan, Color::Default};

    assert(frame.hit_at(0, 0) == Id("canvas"));
    assert(frame.bounds_of(Id("canvas")) == Area(0, 0, 16, 4));
    assert((frame[1, 2].ch == U'X'));

    frame.render(false);
    assert(!frame.raw_output().empty());
    return 0;
}
```

## Errors and edge cases

- **Move-only semantics**: `Frame` deletes its copy constructor and copy assignment operator (`Frame(const Frame&) = delete`) to prevent accidental full-grid buffer copies. Pass `Frame&` by reference.
- **Direct `operator[r, c]` vs. `set_cell()`**: Mutating `frame[r, c]` directly modifies `m_back_buffer` in place without running the wide-character continuation cleanup or hit-buffer tagging performed by `set_cell()`. Use `set_cell()` whenever writing width-2 glyphs or `id` tags.
- **Zero-output clean frames**: If no non-continuation cell differs between `m_front_buffer` and `m_back_buffer` and the cursor state has not changed, `render()` returns immediately without emitting `[?2026h` or calling `write_all()`.
- **Write failure recovery**: If `write_all(STDOUT_FILENO, m_output)` fails during `render(true)`, `Frame` fills `m_front_buffer` with `Cell{U'ÿ'}` so the next render pass forces a full screen repaint.
