```cpp title="dashboard.cpp" render="60x12"
ListState hosts({"alpha", "beta", "gamma"});
hosts.set_selected(1);
std::vector<uint64_t> load = {2, 4, 3, 6, 8, 7, 5, 9, 6, 4, 7, 10};

auto [left, right] = Layout::horizontal<2>(frame.area(), {Constraint::percent(35), Constraint::fill()});
List(hosts).title("Hosts").highlight_symbol("> ").border_style(BorderStyle::Rounded).draw(frame, left);

auto [top, bottom] = Layout::vertical<2>(right, {Constraint::fixed(3), Constraint::fill()});
Box().title("CPU").border_style(BorderStyle::Rounded).draw(frame, top);
Gauge().percent(64).label("64%").draw(frame, top.inset(1, 1, 1, 1));
Box().title("Load").border_style(BorderStyle::Rounded).draw(frame, bottom);
Sparkline().data(load).draw(frame, bottom.inset(1, 1, 1, 1));
```

<section class="koto-section not-content">
  <p class="stamp">[ Why koto ]</p>
  <h2>Small surface, <em>no surprises.</em></h2>
  <div class="koto-grid">
    <div class="koto-card">
      <p class="stamp"><span>Rendering</span><span>01</span></p>
      <h3>No widget tree</h3>
      <p>State lives in your variables. Widgets are cheap values you draw each frame, so there is nothing to keep in sync.</p>
      <a href="/concepts/immediate-mode/">Immediate mode →</a>
    </div>
    <div class="koto-card">
      <p class="stamp"><span>Output</span><span>02</span></p>
      <h3>Only what changed</h3>
      <p>A double-buffered diff renderer writes changed cells inside a synchronized update, so frames are minimal and tear-free where supported.</p>
      <a href="/concepts/frames-diff-renderer/">The renderer →</a>
    </div>
    <div class="koto-card">
      <p class="stamp"><span>Input</span><span>03</span></p>
      <h3>Mouse and focus built in</h3>
      <p>Every drawn cell carries an id, so clicks resolve to widgets, focus follows the mouse, and modal dialogs trap Tab.</p>
      <a href="/concepts/ids-hit-buffer/">Hit buffer →</a>
    </div>
    <div class="koto-card">
      <p class="stamp"><span>Quality</span><span>04</span></p>
      <h3>Testable without a terminal</h3>
      <p>Draw into an in-memory frame and assert on plain text. Every example in these docs is tested that way.</p>
      <a href="/guides/headless-testing/">Headless testing →</a>
    </div>
  </div>
</section>
